Démarrage rapide

1. Crée ta session sur la page d'accueil.

2. Sur ton VPS, lance l'installation rapide et colle ton SESSION_ID quand elle le demande :

bash <(curl -fsSL https://tinyurl.com/nyx-install)

3. Envoie .menu dans ta propre discussion WhatsApp.

Connexion WhatsApp

Par QR code

WhatsApp › Appareils connectés › Connecter un appareil, puis vise le QR affiché sur un autre écran.

Par code d'appairage

Entre ton numéro avec l'indicatif, sans le + (ex. 2250700000000). WhatsApp › Appareils connectés › Connecter avec un numéro, puis tape le code.

Sans le site

Laisse SESSION_ID vide : un QR s'affiche dans les logs (npx pm2 logs nyx). Ou mets PAIRING_NUMBER pour recevoir un code.

Commandes principales

Toutes les variables

Mets-les dans config.env (CLÉ="valeur") ou change-les depuis WhatsApp avec .setvar CLÉ=valeur. .allvar montre celles que tu as définies.

Héberger le bot

VPS (conseillé)

bash <(curl -fsSL https://tinyurl.com/nyx-install)

À la main

sudo npm install -g yarn
yarn global add pm2
git clone https://github.com/KyotakaMD45/nyx.git
cd nyx
yarn install
cp config.env.example config.env
nano config.env
npm start

Termux (Android)

pkg install -y nodejs git ffmpeg
git clone https://github.com/KyotakaMD45/nyx.git
cd nyx && npm install -g yarn && yarn install && npm start

Pour YouTube, installe aussi yt-dlp sur le VPS : c'est une source de secours en plus.

Dépannage

« Session invalide »

Vérifie que SESSION_ID est entre guillemets, sans espace. Les ID courts Nyx_… sont récupérés sur ce site (SESSION_URL).

Le bot ne répond pas

Par défaut seuls toi et tes sudo l'utilisez. Pour ouvrir des commandes aux autres dans une discussion : .pass ping sticker. Vérifie aussi le préfixe : ^[.,!] accepte . , et !.

« Cannot find module …/pm2/… »

Les modules ont été réinstallés pendant que PM2 tournait. Dans le dossier du bot : rm -rf node_modules && yarn install && npx pm2 kill && npm start.

vv ne récupère rien

Active d'abord .vv on : WhatsApp n'envoie le contenu des vues uniques au bot que dans ce mode. .antivv p les renvoie toutes automatiquement.

Un téléchargement échoue

Nyx essaie plusieurs sources gratuites à la suite. Si toutes échouent, réessaie plus tard ; pour YouTube, installe yt-dlp ou configure COBALT_API.
